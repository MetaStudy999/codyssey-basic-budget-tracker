# B2-1 03-1~03-8 단계별 재사용 기획 프롬프트·누락 검토 기록 V1.1

> 2026-10-30 기존 V0.1 요약을 근거로 **현재 새로 명문화한 재사용 프롬프트**다. 과거에 이 프롬프트들을 그대로 실행했다는 기록은 아니다. 현재 작업은 문서 설계만 수행하며 신규 소스·런타임은 NOT_STARTED/NOT_VERIFIED.

## 공통 입력·출구 조건
- 입력: 제2기 B2-1 공식 PDF, b2-1-evaluation.md, 현재 Git HEAD, 이전 단계 문서, archive의 읽기 전용 참고자료.
- 금지: 공식 요구의 임의 축소·추가, 과거 PASS 재사용, 비밀키·개인 거래 노출, 개발 승인 없는 04-src 작성/명령 실행.
- 출력: 실제 단계 MD·상대 링크·설계 선택·반례/오류·Mermaid·입문자용 5분 예·REQ/LO/T/E 연결·DOC 판정.
- 검증: 정적 링크/코드 블록, 내용 일관성, PDF 출처, 책임 경계, 승인 상태를 3회 이상 확인.
