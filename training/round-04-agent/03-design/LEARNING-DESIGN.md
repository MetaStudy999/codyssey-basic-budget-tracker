## 5분 첫 활동: 리스트와 수입·지출
**쉬운 한 문장:** 리스트(List)는 수입·지출 숫자를 차례로 담는다. 하지만 저장·유효성 검사는 별개다.
**비유:** 노트에 항목을 쭉 쓰는 방식. 실제 JSONL 파일은 종이 노트와 달리 전자 파일이며, 종료 후 영구 보존하려면 파일 쓰기가 필요하다.
~~~mermaid
flowchart LR
 A["입력: 3000·2000"] --> B["리스트로 항목 기록"] --> C["차례로 더함"] --> D["예상합계 5000"]
~~~
**예측:** 3000과 2000을 더하면 얼마인가? **답:** 5000. **종이 실습:** 값 하나를 4500으로 바꾸고 합계를 예측해 설명한다. 이 활동은 EDUCATIONAL_EXAMPLE / NOT_EXECUTED이며 실제 CLI 결과가 아니다.

## 9요소 기술 학습 프레임
용어(한글·영문·통용약어) → 개념(왜) → 정확한 비유와 한계 → 아키텍처(입력·처리·저장·출력) → 실제 승인된 신규 코드 → 실행 흐름 → 오류 해결 → 독립 실습 → 평가/복습. 공식 약어가 없으면 임의 약어를 만들지 않는다.

## PRIMM과 힌트
Predict(코드 실행 예상) → Run(승인 후 실제 수행) → Investigate(변수/파일 상태 조사) → Modify(한 줄 변경·재실행) → Make(새 기능 독립 구현).
H1 정답 없는 질문; H2 관련 개념; H3 실행 절차; H4 예제 풀이. 평가 전 도움 수준을 명시하고 독립 L4/L5 실습에서 AI 지원 사용을 별도로 기록한다.

## 숙달 평가 L1~L5
L1 실제 신규 코드 보며 역할 설명 / L2 구조도만 보고 입력→파일→결과 설명 / L3 자료 없이 저장 방식 선택을 이유와 함께 설명 / L4 빈 프로젝트에서 작은 거래 입력·합계 핵심 기능 재구현 / L5 새로운 지출 분류·깨진 파일 조건에서 설계·검증. 공식 미션 PASS와 학습 MASTER는 독립 판정.
