## 5. 한글·영어·공식 약어와 설명·재현 확인

**처음 등장:** 한글명(English Full Name, 공식 약어). 널리 쓰이는 약어가 **없으면 임의로 만들지 않습니다.**

| 한글명 | 영어 원명 | 공식·통용 약어 | 입문자를 위한 한 줄 설명 |
|---|---|---|---|
| **파이썬** | Python | 없음 | 자료·명령을 처리하는 프로그래밍 언어 |
| **리스트** | List | 없음 | 순서가 있는 여러 값을 담는 자료형 |
| **딕셔너리** | Dictionary | 없음 | 키와 값의 대응 관계를 저장 |
| **입출력** | Input/Output | I/O | 파일·표준 입력과 출력 |

**자기 설명(Explain):** 리스트(List)는 여러 항목을 순서대로 담습니다. 두 지출 금액을 순서대로 기록하면 각 값을 순회해 합계를 계산할 수 있습니다.

**종이 재현(Reconstruct, 실행 전 예상)**
1. 금액 3000과 2000을 자료에 담는다고 가정.
2. 각 값을 순서대로 더함.
3. 예상 합계 5000원을 설명.

**오류·오해 예방:** 리스트는 자동으로 수입·지출이 옳은지 검사해주지 않습니다. 검증 규칙과 계산 로직이 별도로 필요합니다.

**확인 질문:** 책을 덮고 핵심 용어를 자기 말로 말할 수 있는가? 위 입력→처리→예상 결과를 종이에 다시 그릴 수 있는가?

**판정 주의:** 종이 재현과 기대 결과는 교육용이고, 코드 구현·실행·학습자의 독립 숙달 L4~L5는 아직 NOT_VERIFIED 또는 NOT_STARTED입니다. [00단계 시작으로 돌아가기](README.md).
