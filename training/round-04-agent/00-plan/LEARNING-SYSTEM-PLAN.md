## 1. 교육 목적·방법

용어 설명→원리 이해→코드 동작 예측→코드 추적·수정→독립 작성·오류 해결→자기 설명→새 문제 응용. 학습자 실습·실행·평가의 실제 성과로 판정하며 AI가 대신 학습 완료를 선언하지 않는다.

**16종 방법:** M01 용어카드 · M02 개념관계도 · M03 비유/4컷 · M04 Why 질문 · M05 기술 비교 · M06 실행 예측 · M07 코드 추적 · M08 Parsons 코드 조립 · M09 빈칸 · M10 수정 실험 · M11 디버깅 · M12 독립 구현 · M13 자기 설명 · M14 응용 · M15 간격 복습 · M16 AI 피드백. 목표·난이도에 필요한 활동만 선택.

**PRIMM:** Predict, Run, Investigate, Modify, Make. **AI 힌트:** H1 질문, H2 개념, H3 절차, H4 예제 해설. 도움 수준과 평가 허용 범위 기록.

**L1~L5:** 코드 보며 설명, 도식만 설명, 자료 없이 설명, 빈 환경 재현, 새 문제 적용. 미션 기능 PASS/콘텐츠 품질 PASS/학습 MASTER는 별도 판정.

**회상 복습:** 학습 직후, 1·3·7·14·30일 운영안. 개별 오답·기억 유지에 따라 유연하게 조정. 사전·사후 동등 난이도 문제와 독립 실습 결과로 성취 측정.
